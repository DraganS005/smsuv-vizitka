# smsuv-vizitka

A simple one-page portfolio website for a fictional small digital studio, Kres Digital.
Everything is in a single `index.html` file with inline CSS and embedded SVG illustrations.

## Sections

- Hero
- Projects (Projekti)
- News (Novice)
- Photos (Fotografije)
- About (O nas)
- Contact (Kontakt)

## Usage

Open `index.html` in a browser — no build step or server required. The page content is in Slovenian.
